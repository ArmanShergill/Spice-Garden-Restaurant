# Spice Garden Restaurant Website 🌶️

A modern and responsive restaurant website designed for Spice Garden Restaurant, showcasing authentic Indian cuisine, menu highlights, online reservations, contact information, and a smooth user experience across all devices.

## Live Demo
https://spice-garden-restaurant-1406.netlify.app/

## Features
- Responsive Design
- Interactive Navigation
- Food Menu Section
- Online Reservation Form
- Contact & Location Section
- Modern UI/UX
- Fast and Lightweight

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to provide an attractive online presence for Spice Garden Restaurant and improve customer engagement through a user-friendly web experience.
